# 每日工作日报

## 工作流程

1. 运行 `scripts/collect_git_stats.py` 收集今日 git 提交数据
2. 根据收集到的数据，智能总结今天的工作内容
3. 以简洁的纯文本格式输出日报

## 日报格式

```
📅 今日工作日报 (YYYY-MM-DD)

【工作内容】
1. [项目名] - [一句话总结工作内容]
2. [项目名] - [一句话总结工作内容]

【详细说明】
- [具体改动/功能/修复的描述]

【代码变更】
- 提交数: X
- 修改文件: X 个
```

## 总结原则

- 用简洁的中文描述，避免直接罗列 commit message
- 按项目/功能模块归类，而非按时间顺序
- 突出主要工作成果，忽略小修改（如 typo、格式调整）
- 如果涉及多个项目，按重要性排序
- 适当合并相似的工作内容
